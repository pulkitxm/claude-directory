# Radial shader experiment

An interactive radial shader preview with controls and implementation notes. Run `npm ci` and `npm run dev`; use `npm run build` for the production build.

The shader core is adapted from [Dalim](https://github.com/dalim-in/dalim/blob/edca0e566a2570cad00d8026200d854356403225/apps/ui/registry/default/ui/backgrounds/shader-ripple.tsx) under the MIT license.
