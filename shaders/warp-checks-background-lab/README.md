# Warp Checks Background Lab

An interactive shader study with live parameter controls and implementation notes. Run `npm ci` and `npm run dev`; build with `npm run build`.

The shader renderer uses Paper Shaders0.0.82 under Apache-2.0 with a new functional API binding. Original interface work follows the repository MIT license. Imported packages retain their own licenses; see [THIRD_PARTY_NOTICES.txt](./THIRD_PARTY_NOTICES.txt).
