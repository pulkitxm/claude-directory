# Licensing

The root [MIT license](LICENSE) covers contributor-owned code and documentation. Third-party software and resources retain their applicable licenses.

Exact runtime package versions, licenses and origins are recorded in [dependency licenses](compliance/dependency-licenses.json). Built npm previews include installed license and notice texts in `THIRD_PARTY_NOTICES.txt`. Package changes require matching license records.

Licensed component and shader integrations are listed in [source licenses](compliance/source-licenses.json). Inline icon geometry is documented in [icon provenance](compliance/inline-icon-provenance.json), with the complete upstream MIT, ISC and Apache-2.0 notices preserved in the linked files.

[Third-party notices](THIRD_PARTY_NOTICES.md) and project-specific notices contain the applicable copyright, attribution and license terms. These terms remain in force independently of the root license.
