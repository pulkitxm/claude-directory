# Asset provenance

The current source tree contains no standalone images, fonts, video, audio, model files or media archives. ASSET_PROVENANCE.json has an empty local-assets list and retains the separately licensed runtime dependency and host-service records. All 151 previously retained original media files were removed in the media-free cleanup, including geometric SVGs, favicons and the synthesized gradient video. CSS-generated drawings replace their visible slots, and the scroll animation draws an interactive light scene directly from code. No removed commercial media was embedded, renamed or transformed as part of this change. System fonts remain in use.

[compliance/media-removal.json](compliance/media-removal.json) records every removed path and SHA-256, its previous provenance, the affected projects and the reviewed current source hashes. Prior audit and restoration snapshots remain historical evidence, rather than claims about the current file tree.

There are no source-declared browser CDN dependencies. The procedural coastal scene bundles Three.js 0.160.0 and OrbitControls from the pinned npm package; its complete MIT notice is preserved in the project and the published notices. npm runtime package/version/license records are in compliance/dependency-licenses.json; the publication builder preserves installed license/notice texts in each preview's THIRD_PARTY_NOTICES.txt. These dependency licenses do not license third-party demo media.

Restored library integrations keep their specific upstream source licenses. [compliance/restored-projects.json](compliance/restored-projects.json) and its linked review records identify pinned primary source revisions, source comparisons, exact current file hashes, complete notice files and verified package grants. Source-project notices accompany the built preview. A library grant covers the named source only, not an unrelated vendor template, marketing page or asset.

Inline SVG paths, shader programs and drawing regions also require review. [compliance/inline-icon-provenance.json](compliance/inline-icon-provenance.json) records exact matches to licensed open-source geometry, the source, applicable license and complete notices. This is scoped to the matched geometry and does not establish the historical import version. Unmatched simple drawings and custom charts were reviewed separately against their original briefs. [compliance/inline-artwork.json](compliance/inline-artwork.json) pins each reviewed source file containing inline artwork or procedural shader code and the required notice/license files; a changed source hash requires renewed manual review. This safeguard does not determine whether an unfamiliar illustration is protected.

The live host can also inject Cloudflare's provider-served Web Analytics beacon and email-address decoder into browser responses. These provider scripts are absent from this repository and the built artifact, remain governed by the provider's service terms rather than the repository MIT license, and were not vendored or republished as repository source. These transformations are documented in [Cloudflare's analytics setup](https://developers.cloudflare.com/web-analytics/get-started/) and [email-obfuscation instructions](https://developers.cloudflare.com/waf/tools/scrape-shield/email-address-obfuscation/). Provider-service metadata is recorded separately in ASSET_PROVENANCE.json.

Standalone media files cannot be added to this repository under the current distribution policy, even with a provenance entry. New inline drawings and procedural graphics require an authorship or source-license review, preserved notices and exact source hashes before publication. Record manual review for suspicious build-hash filenames. Never rename or transform disputed files to disguise origin. Captures and commercial template source remain prohibited even if ignored by Git.

Run `node scripts/check-compliance.mjs` before commits, PRs and publishing. This detects common mistakes and does not prove copyright compliance. Review independent authorship, design similarity, trademark, publicity and other rights manually.
