# Asset provenance

ASSET_PROVENANCE.json is the machine-readable manifest for every retained local media file, with exact path, SHA-256, origin, license, kind and redistribution permission. All replacement SVGs are new geometric drawings created locally without modifying old media. The Apex light-study video is newly synthesized from a mathematical gradient; its generation method, fixed seed, dimensions, duration and SHA-256 are recorded in the manifest. The exact original executable command was not retained. System fonts replace the old downloaded fonts. Old demos and posters were removed and have not been regenerated from disputed designs.

The only external browser dependency is Three.js 0.160.0 and its OrbitControls module from unpkg. Its MIT rights notice is preserved in THIRD_PARTY_NOTICES.md. Network availability is required for that scene. npm runtime package/version/license records are in compliance/dependency-licenses.json; the publication builder preserves installed license/notice texts in each preview's THIRD_PARTY_NOTICES.txt. These dependency licenses do not license third-party demo media.

Inline SVG paths and regions are also assets. [compliance/inline-icon-provenance.json](compliance/inline-icon-provenance.json) records exact matches to licensed open-source geometry, the source, applicable license and complete notices. This is scoped to the matched geometry and does not establish the historical import version. Unmatched simple drawings and custom charts were reviewed separately against their original briefs. [compliance/inline-artwork.json](compliance/inline-artwork.json) pins each reviewed source file containing inline artwork and the required notice/license files; a changed source hash requires renewed manual review. This safeguard does not determine whether an unfamiliar illustration is protected.

To add an asset, establish ownership or an explicit redistribution grant, record the original source and applicable license, preserve required notices, hash the exact file, and update the manifest. Record manual review for suspicious build-hash filenames. Never rename or transform disputed files to disguise origin. Captures and commercial template source remain prohibited even if ignored by Git.

Run `node scripts/check-compliance.mjs` before commits, PRs and publishing. This detects common mistakes and does not prove copyright compliance. Review independent authorship, design similarity, trademark, publicity and other rights manually.
