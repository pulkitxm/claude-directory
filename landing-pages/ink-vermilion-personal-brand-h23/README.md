# Ink & Vermilion : Editorial Personal-Brand Landing Page for a Marketing Consultant

An independent interface experiment with fictional content. The layout and interactions explore editorial personal-brand landing page for a marketing consultant (vanilla html/css/js).

Serve this folder with `python3 -m http.server 8000` and open the displayed address.

Visuals are rendered from source code. Typography uses system fonts.
