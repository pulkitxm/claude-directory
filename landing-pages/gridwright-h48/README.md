# Gridwright : Neo-Structuralist Blueprint Developer-Infrastructure SaaS Landing Page

An independent interface experiment with fictional content. The layout and interactions explore neo-structuralist blueprint developer-infrastructure saas landing page (html, css, vanilla js).
