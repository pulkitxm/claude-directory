# Nocturne Bento : Midnight Atelier Designer Portfolio with Bento Grid Hero

An independent interface experiment with fictional content. The layout and interactions explore midnight atelier designer portfolio with bento grid hero (vanilla html/css/js, static).

Serve this folder with `python3 -m http.server 8000` and open the displayed address.

Visuals are rendered from source code. Typography uses system fonts.

Asset and dependency licensing is recorded in the root [provenance manifest](../../ASSET_PROVENANCE.md).
