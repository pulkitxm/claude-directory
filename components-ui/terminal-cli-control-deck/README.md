# Terminal CLI Control Deck : Phosphor-Green Infrastructure Dashboard

An independent interface experiment with fictional content. The layout and interactions explore phosphor-green infrastructure dashboard (react + vite + tailwind css).

Run `npm install`, `npm run dev`, or `npm run build`. The terminal and access form operate on synthetic local data.

Typography uses system fonts.
