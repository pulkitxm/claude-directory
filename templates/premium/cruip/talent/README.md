# Talent

[![Watch Demo](./poster.jpg)](./demo.mp4)

A locally vendored reproduction of Cruip's Talent marketplace template.

## Pages

- Home
- Schedule a call
- Sign in
- Reset password

## Running locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/templates/premium/cruip/talent/`.

The template uses local CSS, JavaScript, fonts, images, video, and favicon assets. It does not require a build step.
