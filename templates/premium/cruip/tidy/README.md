# Tidy

[![Watch Demo](./poster.jpg)](./demo.mp4)

A locally vendored reproduction of Cruip's Tidy marketing template with all twelve current routes.

## Pages

- Home
- Pricing
- About
- Blog
- Blog post
- Wall of Love
- Wall of Love story
- 404
- Support
- Sign in
- Request demo
- Reset password

## Running locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080/templates/premium/cruip/tidy/`.

The template uses local CSS, JavaScript, images, video, and favicon assets. It does not require a build step.
