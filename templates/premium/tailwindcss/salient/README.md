# Salient — Tailwind UI SaaS Landing Page Template

A pixel-faithful clone of the **Salient** template from Tailwind UI — a clean, modern SaaS marketing site for "TaxPal" bookkeeping software.

## Pages

| Page | File |
|------|------|
| Home | `index.html` |
| Sign In | `login.html` |
| Sign Up | `register.html` |

## Features Reproduced

- Sticky header with mobile hamburger menu
- Hero section with centered headline, CTAs, and trusted-by logos
- Tabbed primary features section with app screenshots (Payroll, Expenses, VAT, Reporting)
- Secondary features 3-column grid with scroll-reveal animation
- Call-to-action banner with background image
- Testimonials grid with featured (blue) card variant
- 3-tier pricing table (Starter, Small Business, Enterprise)
- FAQ accordion (9 items, 2-column layout)
- Footer with nav links and copyright
- Login / Register auth pages with split decorative panel layout

## Tech

Plain HTML + CSS + vanilla JS. No build step. Assets vendored locally.

**Fonts:** Inter (body), Lexend (display)  
**Colors:** Blue-600 (#155DFC) primary, Slate-900 (#0F172B) buttons/text
