## SUMMARY

SALIENT IS A CLEAN, MODERN SAAS LANDING PAGE TEMPLATE FOR "TAXPAL" — A FICTIONAL BOOKKEEPING SOFTWARE. THE TEMPLATE FEATURES A HERO WITH GRADIENT BACKGROUND, TABBED FEATURES SECTION WITH APP SCREENSHOTS, CALL-TO-ACTION, TESTIMONIALS CAROUSEL/GRID, PRICING TIERS, FAQS ACCORDION, AND A FOOTER. COMPANION AUTH PAGES INCLUDE A LOGIN AND REGISTRATION FORM.
