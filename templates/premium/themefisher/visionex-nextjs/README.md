# Visionex Next.js

A faithful static reproduction of the Themefisher Visionex Next.js template, including all 37 live routes, responsive layouts, navigation, tabs, pricing controls, accordions, and forms.

[![Watch Demo](./poster.jpg)](./demo.mp4)

## Run locally

Serve this directory with any static file server. For example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
