# Phanatik: Editorial News and Podcast Template

[![Watch Demo](./poster.jpg)](./demo.mp4)

Phanatik is a complete static HTML reproduction of the Phanatik editorial publishing website by Lexington Themes. Its dense but disciplined layout combines newspaper-inspired typography, clear content hierarchy, compact navigation, subscription surfaces, and dedicated podcast presentation.

The project contains all 103 pages reachable from the live interface and search data, including news sections, articles, podcast episodes, author profiles, job listings, help center entries, account pages, legal content, and the design system.

## Page groups

- 33 news, article, and topic pages
- 21 podcast, episode, and podcast topic pages
- 11 author pages
- 12 jobs and application pages
- 11 help center pages
- 5 design system pages
- 3 account pages
- 7 primary, marketing, legal, and utility pages

## Interactions

- Responsive expandable navigation
- Search modal with keyboard controls and real-time filtering
- Account, membership, application, and contact forms
- Podcast controls and tabbed content where available
- Live date and ticker presentation

## Run

Serve the project directory with any static file server:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Assets

The page markup and styles mirror the original deployment. Images, fonts, and supporting scripts load from the provider's published asset URLs.
