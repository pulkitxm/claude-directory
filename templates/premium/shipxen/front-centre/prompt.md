## SUMMARY

FRONT CENTRE IS A BRIGHT, FRIENDLY MARKETING LANDING PAGE FOR A FICTIONAL
"FRONT-END LEARNING CENTER". IT PAIRS A WARM CREAM/LIGHT-YELLOW BACKDROP
(`#FFF9DA`) WITH A YELLOW PRIMARY BUTTON (`#FBD950`) AND CYAN SECONDARY ACCENTS
(`#67E8F9` / CYAN BANDS `#E1FAFE`). HEADINGS ARE SET IN **ROBOTO** (BOLD/600),
WHILE ALL BODY COPY USES **ROBOTO MONO** — THE MONOSPACED BODY IS THE TEMPLATE'S
DEFINING TYPOGRAPHIC SIGNATURE. THE PAGE IS A SINGLE SCROLLING DOCUMENT (NO
SEPARATE SUB-PAGES; THE HEADER NAV POINTS AT THE SHIPIXEN MARKETING SITE AND IN-
PAGE ANCHORS). IT IS BUILT FROM A STACK OF SECTIONS: A SLATE PROMO BAR, A
STICKY HEADER, A HERO WITH A "PRODUCT OF THE DAY" BADGE AND A GRADIENT-BORDERED
DASHBOARD MOCKUP, A LOGO CLOUD, ALTERNATING IMAGE/FEATURE ROWS, A "DEVTOOLS"
PRODUCT BLOCK, A COURSES GRID OF FOUR FEATURE CARDS WITH VIDEO THUMBNAILS, A
CYAN STATS BAND, A MASONRY TESTIMONIALS GRID, A FINAL CTA, A CYAN FAQ ACCORDION,
AND A FOUR-COLUMN SHIPIXEN FOOTER WITH PRODUCT-HUNT BADGES.

- DASHBOARD MOCKUP FRAME: MULTICOLOR GRADIENT GLOW (PURPLE→PINK→ORANGE→CYAN) BEHIND A DARK UI IMAGE
- DARK THEME: NEAR-BLACK BACKGROUND (`hsl(20 14% 4%)`), LIGHT TEXT — REACHED VIA THE HEADER THEME TOGGLE

### TYPOGRAPHY

- HEADINGS: **ROBOTO** (`assets/fonts/roboto-400.ttf`, `roboto-700.ttf`). H1 ≈ `36px` / WEIGHT `600` / LINE-HEIGHT `45px`; SECTION H2 BOLD; FAQ/CARD H3 BOLD.
- BODY: **ROBOTO MONO** (`assets/fonts/roboto-mono-400/500/600.ttf`). HERO SUB ≈ `18px` / `400`; CARD COPY `14–16px`; MONOSPACED EVERYWHERE FOR PARAGRAPH TEXT, LABELS, NAV, BUTTONS.
- LOADED VIA LOCAL `@font-face` (GOOGLE FONTS ROBOTO + ROBOTO MONO), VENDORED.

### SPACING / RADII / SHADOWS

- CONTENT WIDTH: CENTERED MAX-WIDTH CONTAINER (≈ `max-w-6xl`), GENEROUS VERTICAL SECTION PADDING (`py-16`–`py-24`).
- BUTTONS: ROUNDED (`rounded-md`), PADDED PILL-ISH; PRIMARY YELLOW + OUTLINE "LEARN MORE".
- CARDS (COURSES / TESTIMONIALS / FAQ ITEMS): ROUNDED `rounded-xl`, HAIRLINE BORDER, LIGHT SHADOW.
- DASHBOARD MOCKUP: `rounded-xl` IMAGE WITH A BLURRED MULTICOLOR GRADIENT BACKDROP.
- VIDEO THUMBNAILS: DARK GRADIENT RECTANGLE WITH A CENTERED CYAN OUTLINE PLAY TRIANGLE.

### ICONS

- **LUCIDE** OUTLINE ICONS, INLINED AS SVG: `chrome`, `figma`, `github`, `framer` (LOGO CLOUD); `play` (VIDEO CARDS); `star` (RATINGS); `badge-check` (VERIFIED TESTIMONIALS); `chevron-down` (FAQ); `sun` (THEME TOGGLE); `check` (FEATURE LISTS); PLUS A SHIELD GLYPH FOR THE "FRONT CENTRE" WORDMARK.

### ANIMATION / EASINGS

- HOVER: BUTTONS / LINKS / CARDS USE `transition-colors`/`opacity` ≈ `150–200ms ease`. YELLOW + CYAN BUTTONS DARKEN SLIGHTLY; NAV LINKS RECOLOR; OUTLINE BUTTON GAINS A TINT.
- FAQ ACCORDION: RADIX-STYLE — CLICK A QUESTION TO TOGGLE `data-state` CLOSED↔OPEN (`aria-expanded` FALSE↔TRUE); PANEL HEIGHT ANIMATES `0↔auto` (`accordion-down`/`accordion-up` KEYFRAMES) AND THE CHEVRON ROTATES `0↔180deg`. ITEMS TOGGLE INDEPENDENTLY.
- THEME TOGGLE: HEADER SUN/MOON BUTTON TOGGLES `light`/`dark` ON `<html>` (DEFAULT `light`), PERSISTED IN `localStorage`, SWAPPING THE WHOLE PALETTE VIA CSS VARIABLES.
- ENTRANCE: HERO CONTENT + BADGE FADE/TRANSLATE-Y IN ON LOAD; BELOW-THE-FOLD SECTIONS REVEAL ON SCROLL VIA `IntersectionObserver` + CSS TRANSITION (FRAMER-MOTION-STYLE), `≈400–600ms ease-out`.
