## SUMMARY

SPECTA IS A SINGLE-PAGE, DARK-THEME SAAS LANDING PAGE FOR A FICTIONAL AI-POWERED VIDEO EDITING TOOL ("CREATE & EDIT STUNNING VIDEOS WITH AI"). IT IS ONE OF SHIPIXEN'S LANDING-PAGE TEMPLATES, BUILT ON THE PAGE UI / SHADCN COMPONENT SYSTEM (NEXT.JS + TAILWIND). THE DEMO PRESENTS A SINGLE ROUTE — THERE ARE NO TEMPLATE-INTERNAL SUB-PAGES; ALL NAV / FOOTER LINKS POINT BACK TO THE SHIPIXEN MARKETING SITE OR EXTERNAL TOOLS AND THE CTA BUTTONS ARE SAME-PAGE ANCHORS (`#`). THE CLONE THEREFORE REPRODUCES THE ENTIRE EXPERIENCE AS ONE PAGE (`index.html`).

THE PREVIEW-HOST CHROME (THE SHIPIXEN TOOLBAR, TEMPLATE-NAME LABEL, PREVIEW/CODE TABS, AND VIEWPORT TOGGLES) IS NOT PART OF THE TEMPLATE AND IS NOT REPRODUCED; THE CLONE IS NATIVELY RESPONSIVE INSTEAD.
