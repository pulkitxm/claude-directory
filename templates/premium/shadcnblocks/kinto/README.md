# Kinto Journaling Template

[![Watch the demo](./poster.jpg)](./demo.mp4)

Kinto is a self-contained static reproduction of the Shadcnblocks journaling product template. It includes marketing, pricing, company, changelog, authentication, legal, blog index, and nine article routes.

## Run locally

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## Included behavior

- Responsive floating navigation and full-screen mobile menu
- Light and dark themes with local persistence
- Dismissible purchase banner
- Expandable blog index with three additional articles
- Functional authentication form fields
- Local fonts and imagery

The implementation uses plain HTML, CSS, and JavaScript with no build step or external runtime dependency.

Original reference: <https://kinto-nextjs-template.vercel.app/>
