# Plasma

A faithful static reproduction of the Shadcnblocks Plasma template, including all 16 live routes, responsive layouts, theme controls, navigation, tabs, accordions, carousels, documentation controls, and forms.

[![Watch Demo](./poster.jpg)](./demo.mp4)

## Run locally

Serve this directory with any static file server. For example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
