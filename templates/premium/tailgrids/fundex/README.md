# Fundex Personal Finance Dashboard

[![Watch the Fundex demo](./poster.jpg)](./demo.mp4)

A responsive personal finance dashboard with transactions, analytics, budgets, settings, persistent light and dark themes, and interactive data controls. The static project requires no build step.

## Pages

| File | View |
| --- | --- |
| `index.html` | Dashboard |
| `transactions.html` | Transactions |
| `analytics.html` | Analytics |
| `budgets.html` | Budgets |
| `settings.html` | Settings |

## Run locally

Serve this directory with any static file server, then open `index.html`.
