# FinCash Financial Landing Page

[![Watch the FinCash demo](./poster.jpg)](./demo.mp4)

A responsive financial product website with feature, pricing, and contact pages, persistent light and dark themes, and a testimonial carousel. The static project requires no build step.

## Pages

| File | View |
| --- | --- |
| `index.html` | Home |
| `features.html` | Features |
| `pricing.html` | Pricing |
| `contact.html` | Contact |

## Run locally

Serve this directory with any static file server, then open `index.html`.
